## Sobre o Cenário
O sistema **VetCare** modela a estrutura de dados de uma clínica veterinária para controlar tutores, animais atendidos, médicos veterinários, consultas clínicas, prescrições médicas, catálogo de vacinas e histórico de aplicações (incluindo doses de reforço).
